### 文件结构
- `index.html` — 主页面
- `css/main.css` — 全部样式（深/浅色主题变量、卡片、面板、动画）
- `js/state.js` — 全局状态管理
- `js/canvas-manager.js` — 拖拽平移 + 滚轮缩放 + 触摸手势
- `js/card-renderer.js` — 哲学家卡片 DOM 生成
- `js/connection-renderer.js` — SVG 贝塞尔曲线连线
- `js/panel-controller.js` — SelectionManager（点击高亮）
- `js/theme.js` — 主题/面板/过滤器交互
- `js/app.js` — 入口，加载 JSON 数据、初始化模块
- `data/philosophers.json` — 25位哲学家数据（古希腊→20世纪）
- `data/connections.json` — ~70条思想关系连线（P=赞同/N=批判）

### 功能
- 无限画布拖拽+缩放，CSS transform GPU加速
- 绿色/红色贝塞尔曲线连线，点击高亮
- 左侧面板：12个哲学分支过滤器、选项切换（深色/肖像/标签/Era）、哲学家索引跳转
- 加载动画屏幕
- 本地服务器：python -m http.server 8080，访问 http://localhost:8080

### Bug 修复
- i18n t() 函数单参数调用时未拆分 `ui.` 前缀，导致所有 data-i18n 文本显示为 "ui.xxx" 原始 key
- i18n-data.js 的 idea 条目只有 `{zh}` 缺少 `en` 字段，英文模式下显示 idea id
- i18n-data.js 的 conn 条目是纯中文字符串而非 `{en,zh}` 对象，英文模式下显示中文而非英文
- 全面修复：所有 idea 补全 en 字段，所有 conn 改为 {en,zh} 双语格式
- i18n-data.js 的 name 条目是纯中文字符串，t() 遇到 string 直接返回，导致英文模式下哲学家名也显示中文
- 修复：name 条目全部改为 {en, zh} 双语格式，英文名取自 philosophers.json 原始数据
- 连线改为半圆形弧线，锚点移到 idea-dot 标号点
- 连线去除箭头，绿线(P/赞成)向上弯，红线(N/反对)向下弯
- 修复拖拽浏览时取消选中的bug：删除 theme.js 的 click 监听器，统一由 canvas-manager.js 的 onMouseUp 处理（hasMoved 判断）
- 索引列表加 max-height 独立滚动，过滤器和选项不被挤走
- 修复缩放后文字模糊：will-change:transform 导致 GPU 层只做位图拉伸，缩放结束后需强制重绘。
  添加 scheduleRepaint() 函数，在 onWheel/animateTo/zoomButtons 后延迟 150ms 重新光栅化
