# Philograph 项目 - 工作记忆

## 项目概要
- 哲学思想可视化 web 应用
- 数据结构: philosophers.json (西方), chinese-philosophers.json (中国), connections.json / chinese-connections.json

## 2026-04-13 数据验证结果
- **西方哲学家**: 50位 ✅ (所有3-13条思想，全部有连线)
- **中国哲学家**: 50位 ✅ (所有3-13条思想，全部有连线)
- **西方连线**: 175条 (修复了 heraclitus 和 parmenides 无连线问题)
- **中国连线**: 158条

## 修复记录
- 为罗钦顺 (luojiushun) 添加了第3条思想条目
- 为 Heraclitus 和 Parmenides 添加了15条新连线 (包括互相之间、与 Plato/Socrates/Aristotle/Hegel/Nietzsche/Kant/Spinoza 的关系)

## 关键规则
- 只通过 Python 脚本修改 JSON 文件
- 思想条目: 3-10条 (关键人物如孔子/康德可超10条)
- 连线类型: P(正向/赞同), N(负向/对立)
