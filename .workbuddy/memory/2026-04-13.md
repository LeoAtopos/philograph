- 连线类型: P(正向/赞同), N(负向/对立)

## 2026-04-14 微信小程序适配
- **目录**: `release/wechat/` (不影响网页版代码)
- **架构**: scroll-view + WXML 原生组件列表（放弃 Canvas，真机性能最优）
- **页面**: index（scroll-view 卡片列表+筛选+索引抽屉）、detail（思想+连线关系）
- **放弃 Canvas 原因**: Canvas 2D 在真机上即使只画文字也严重卡顿，是小程序底层渲染限制
- **数据**: JSON → CommonJS require() 内联，无需 wx.request()
- **i18n**: utils/i18n.js + utils/i18n-data.js，支持中英双语
- **数据同步脚本**: data/update_wechat_data.py
- **头像**: 已本地化，全部下载到 release/wechat/images/ (89 张 .jpg, 606KB)
  - 压缩到 200x200px JPEG Q75，总包 0.97MB < 2MB 主包限制
  - 不再需要配置 upload.wikimedia.org 合法域名
  - fazang/zhiyi 源文件损坏（无效图片格式），显示文字占位符
  - philosophers: 47 本地 + 3 空 (Quine/Davidson/Kuhn)
  - chinese-philosophers: 42 本地 + 8 空 (6 原无图 + fazang/zhiyi 损坏)
- **辅助脚本**: data/sync_wechat_portraits.py, compress_wechat_images.py, restore_portraits.py
